Changelog JEI Groups

# 1.4.1
- Removed test group

# 1.4.0
- Updated to JEI 29.21.0.68

# 1.3.0
- Whole groups can no longer be bookmarked, its very buggy 
- Items inside groups can now be bookmarked without potentially crashing the game
- Improved rendering of item stacks on groups to hopefully stop 2 different items overlapping when searching

# 1.2.4
- Tooltips no longer show up on items in creative mod and other places 

# 1.2.3
- Using ! inside a items filter will now exclude that item from the group

# 1.2.2
- Searching for an item in a group will now show the item as the group icon instead of the default item icon

# 1.2.1
- Added wildcard implementation allowing for item to be added like "*:*_spawn_egg" which will add all spawn eggs to a group
- Added a bunch of new groups 

# 1.2.0
- This is a fork from 1.0.3 to better implement features and rewrite the code significantly
- Optimized inputs
- When a group is expanded, it will now show the contents together instead of in the original positions 
- Groups when expanded now have a border 
- jsons can now set border_color, overlay_tint, plus_icon_color, background_color, and border_thickness. If these values are missing defaults will be used
- Group icons no longer need to be the first item in the group can be any item
- When searching in jei items inside groups will now show as if a normal jei search has happened
- Opened groups are now persistent between sessions
- Moved locations back to assets instead of data making the mod 100% client side, there should be no issues with this mod being on a server
- Newly added groups will now show after doing F3 + T (reloading assets) whilst still in game 
- Added various new categories 

# 1.0.3
- Changed literal components to translatable ones
- Icon is now an item stack not an identifier
